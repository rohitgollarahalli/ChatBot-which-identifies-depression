# Security Policy

## This project is not a crisis service

This is an academic NLP project. It cannot diagnose anything and it does not
monitor anyone. **If you or someone near you is in crisis or at risk of harm:**

- **United States:** call or text **988** (Suicide & Crisis Lifeline).
- **Elsewhere:** find a local helpline at https://findahelpline.com.
- In an emergency, contact your local emergency services.

Please do not use GitHub issues or security reports to seek help.

## Reporting a vulnerability

Please report security issues privately through GitHub private vulnerability
reporting: open the repository's **Security** tab and choose
**Report a vulnerability**. Do not open a public issue for security problems.
The same private channel is used for Code of Conduct reports.

Include what you found, how to reproduce it, and the version or commit. This is a
volunteer-maintained project, so responses are best effort.

## Scope

Of particular interest: ways to make the crisis screen miss clearly worded crisis
language in a harmful way, unintended disclosure of conversation content, and
vulnerabilities in dependencies or CI configuration.
